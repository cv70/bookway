# Recommend Recall

`recommend-recall` 是候选召回服务。它并行读取优质、新鲜和用户兴趣域内容索引，合并重复候选的召回理由、排除已看内容，并返回统一候选协议；每个召回源在版本化游标中维护独立的位置与完成状态，避免不同排序或领域索引共用偏移量。任一召回源失败时保留其余链路并标记 `degraded=true`，并在后续页保留失败源的位置以供重试；旧的单一偏移游标在滚动发布期间仍被接受。

默认监听 `127.0.0.1:8095`（`RECOMMEND_RECALL_ADDR`），内容上游由 `BBS_LINK_GRPC_URL` 配置；启用服务鉴权时请求会携带 `x-service-token`。
